## Objective

One function decides what each user type may do. The spreadsheet hides or
disables controls the current user is not allowed to use.

## Background

From `features_TODO.md`: *delete, move and role-edit should be HR/admin only;
a MEMBER sees read-only; a GUEST sees less again.*

The server already enforces part of this. `requireAuth` in `utils/auth.ts`
returns 403 for anyone other than ADMIN/HR on protected routes. But that rule
is written inline there, and the frontend has no rule at all. The goal is
**one table of rules** that both sides import. Then "can a MEMBER delete?" has
exactly one answer, in one place.

The rules for this sprint:

| Action | ADMIN | HR | MEMBER | GUEST |
|---|:--:|:--:|:--:|:--:|
| View the org tree, names and roles | ✓ | ✓ | ✓ | ✓ |
| View contact details (emails, Discord, GitHub) | ✓ | ✓ | ✓ | ✗ |
| Move a member (drag & drop) | ✓ | ✓ | ✗ | ✗ |
| Delete a member | ✓ | ✓ | ✗ | ✗ |
| Add / edit a member | ✓ | ✓ | ✗ | ✗ |

## Files you will touch

- `utils/model/permissions.ts` (new)
- `utils/auth.ts`
- `src/components/SpreadsheetLayout.tsx` (conditionals only)
- `src/pages/members.tsx` (pass the current user's type down, or read context)

## What to change

1. In `utils/model/permissions.ts`, define an `Action` union (`"view"`,
   `"viewContact"`, `"move"`, `"delete"`, `"edit"`) and a
   `can(userType: UserType | undefined, action: Action): boolean` built from a
   lookup table, not a chain of `if`s. `undefined` (logged out) can do nothing.0
2. Make `requireAuth` use `can(...)` instead of its inline `ADMIN || HR` check.
   Think about whether it should take the action as a parameter, for example
   `requireAuth("delete")`. Do not re-wire every route this week; just make it
   possible.
3. In the spreadsheet:
   - Without `"move"`: member columns are not `draggable`, have no
     grab cursor, and teams ignore drops.
   - Without `"delete"`: no trash button is rendered. Do not just disable it.
   - Without `"viewContact"`: emails, Discord and GitHub are not rendered.

## How to approach it

- Write `can()` and check every cell of the table above by hand, or with
  tests if Jenny's W45.4.1 has landed. Ask her.
- In `SpreadsheetLayout.tsx`, only **wrap** existing elements in conditionals.
  Maya is restyling the same file in W45.6.2. A PR that moves markup around will
  conflict badly with hers. Message her before you start.
- Hiding a button is not security. Anyone can call the API directly. That is
  why step 2 matters, and why the server stays the real gate.

## Acceptance criteria
