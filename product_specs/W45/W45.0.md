## Objective

Get `npm run build` passing on `main` again, keeping the behaviour of all three
W38 features: the org tree from W38.1, drag & drop from W38.3, and delete with
typed confirmation from W38.4.

## Background

Three feature branches each edited `members.tsx` and `SpreadsheetLayout.tsx`,
and the conflicts were resolved by keeping both sides. Nothing new needs
designing. This is a careful reading job: figure out which side of each
duplicate is current, and keep only that one.

What is broken today:

**`src/pages/members.tsx`**
- `const [appMembers, setAppMembers] = useState(...)` appears twice. This is a
  hard compile error.
- The pre-W38.1 block that hand-builds `team`, `nonDevTeam`, `department` and
  `sector` is still there. It references `Team`, `Department`,
  `OperationsSector` and `currentPositions`, which are no longer imported.
  W38.1.3 replaced all of it with `buildOrganization`.
- `setPendingDelete` exists, but nothing passes a way to call it down to the
  trash button.

**`src/components/SpreadsheetLayout.tsx`**
- `TeamLayout` has its props typed twice. The second, half-finished block uses
  `setMembers` and `onRequestDelete`, while the first uses `onMembersChange`.
- Each member's column is a draggable `<div>` that contains a second draggable
  `<div>` with the same `onDragStart`.
- The trash button calls `onRequestDelete`, which `DepartmentLayout` and
  `OperationsSectorLayout` never pass through.

## Files you will touch

- `src/pages/members.tsx`
- `src/components/SpreadsheetLayout.tsx`

## What to change

1. Read `git log --oneline -15` and the three merge commits (`acf8e97`,
   `1e6a09f` and the W38.4 commit `fb1bebb`) so you know which hunk came from
   which feature.
2. In `members.tsx`, keep **one** `appMembers` state and delete the hand-built
   org block. The page should render `orgTree` from `buildOrganization` and
   nothing else.
3. In `TeamLayout`, settle on **one** props type. Use the names already used in
   `DepartmentLayout` and `OperationsSectorLayout` (`onMembersChange`,
   `handleMoveTeamAPI`) and add `onRequestDelete`.
4. Thread `onRequestDelete` from `members.tsx` down through
   `OperationsSectorLayout` → `DepartmentLayout` → `TeamLayout`, the same way
   `onMembersChange` already goes.
5. Collapse the nested draggable `<div>`s into one. The trash button is
   `absolute`, so the outer element needs `relative`. Check it still lands in
   the corner.

## How to approach it

- Run `npm run build` first and read every error. Fix them top to bottom. The
  type errors are a to-do list of the duplicates.
- Do not "improve" anything while you are in here. Restyling is W45.6.2, and
  moving to the server is W45.1.3. A small diff makes this PR easy to review
  and easy for everyone else to rebase onto.
- Merge this as early in the week as you can. Post in Discord when it lands so
  everyone rebases.
