## Objective

`npm run server` starts without crashing. Every API route lives under `/api`.
Dead server code is gone, and the session secret is no longer hardcoded.

## Background

Your REST surface (PR #10) is solid. Since it merged, a few things have landed
around it that need tidying up.

- **The server crashes on start.** `app.use(cors())` is called, but `cors` is
  never imported. That is a `ReferenceError` the moment the file runs.
- **`server/routes/members.ts` is dead code.** It is an older copy of the
  member routes, with the exact bugs your PR fixed (`:id` vs
  `req.params.email`, `res.status(400)` with no body). Nothing mounts it. Left
  around, someone will eventually "fix" the wrong file.
- **`/members` means two things.** It is the React page *and* the API route.
  Chunlin's dev proxy (W45.1.2) can only forward API calls if they have their
  own prefix, so every API route needs to move under `/api`.
- **The session secret is hardcoded** as `"my-super-secret-key"`. `dotenv` is
  already a dependency.

## Files you will touch

- `server/index.ts`
- `server/routes/members.ts` (delete)
- `.env.example` (new)
- `.gitignore` (confirm `.env` is ignored)

## What to change

1. Import `cors`. With the proxy, the browser never makes a cross-origin call
   in dev, so decide whether `cors()` is still needed at all. If you keep it,
   restrict `origin` to the Vite dev URL rather than allowing everything. Note
   your decision in the PR.
2. Delete `server/routes/members.ts`. First `grep` the repo to confirm nothing
   imports it.
3. Move every route under `/api`: `/api/login`, `/api/logout`,
   `/api/members`, `/api/members/:email/...`. Do it by putting the routes on an
   `express.Router()` mounted at `/api`, not by hand-editing every path string.
   Keep the 404 and error-handler fallbacks at the app level, after the mount.
4. Read the session secret from `process.env.SESSION_SECRET` via `dotenv`. If
   it is missing, log a clear warning and use a dev-only fallback. Do not
   crash, or every new member's first run fails.
5. Add `.env.example` listing `SESSION_SECRET` and `RESEND_API_KEY` (used by
   `server/routes/emailAuth.ts`) with placeholder values and a one-line comment
   each.

## How to approach it

- Run `npm run server` first and watch it crash. Fix the import, then do the
  rest.
- After the move, test **every** route with `curl` or a REST client, both the
  happy path and one error path each. Paste the commands into the PR so
  reviewers can rerun them.
- Tell Chunlin (W45.1.2) and Kevin (W45.2.1) in Discord when this merges. They
  are both waiting on it.
