## Objective

A team in the app looks like a team in the sheet: a title bar, a stats row, a
role-coloured header row, a row-label column, and member columns that line up
row by row.

## Background

`TeamLayout` in `SpreadsheetLayout.tsx` renders each member as a vertical stack
of `<span>`s inside a flex row. Because each stack sizes itself, a missing
Discord in one column pushes that member's GitHub up a row, and nothing lines
up. The sheet is a **grid**: every row means one thing (Name, Email, …) for
every member.

## Files you will touch

- `src/components/SpreadsheetLayout.tsx` (`TeamLayout` only)

## What to change

1. Lay the team out with CSS grid so each attribute is a **row**: Role, Name,
   Email, Discord, Availability, Proficiency, GitHub, in the sheet's order. A
   missing value renders an empty cell, which keeps the rows aligned.
2. Add the row-label column on the left.
3. Title bar: full width, team-header token, team name centred and bold.
4. Stats row (development teams only): the five stats, separated like the
   sheet. Match the sheet's label wording ("Median Proficiency", not "Median
   Team Proficiency").
5. Role cells use the role-colour tokens (leads vs developers, and any others
   from your audit). Put the thick divider between leads and developers.
6. Long emails: truncate with an ellipsis and show the full value in a `title`
   tooltip, as the sheet effectively does.
7. Keep everything W45.0 left working: each member column is still the drag
   unit, and the trash button still appears.

## How to approach it

- The drag unit is a **member column**, but CSS grid lays out rows. Look up
  `display: subgrid` or `grid-auto-flow: column`, which can let one element per
  member still line up row by row. Prototype it in a scratch page before editing
  the real component.
- Kevin (W45.2.3) is adding conditionals around the trash button, `draggable`
  and the contact rows in this same component. Agree on the order with him.
  Whoever merges second rebases. Keep `can()` checks around the **row** for
  contact details, so a guest gets the row hidden, not three empty rows.
- Compare your work against the sheet side by side at the same zoom. Post a
  before/after screenshot in the PR.
